Release-candidate changes
- Puter credits are the only permanently visible AI/provider information.
- Desktop: remaining credits are shown in the left navigation on every view.
- Mobile: the same remaining-credit indicator is shown in the top bar because the left navigation becomes a bottom navigation.
- Removed visible provider/model/API-key controls from Settings.
- ZNAYA AI uses Puter.js only in this release candidate.
- Puter usage is read through puter.auth.getMonthlyUsage().
- Usage is normalized to the familiar 0–1000 display while preserving the account's real remaining allowance ratio.
